# RPI Dashboard

Информационная панель (дашборд) с фиксированным разрешением 1920x480 для экранов нестандартных пропорций (Raspberry Pi / внешние вытянутые дисплеи).

## Стек технологий

- Python 3
- PyQt5 (включая PyQt5.QtSvg для векторных иконок)
- requests
- python-dotenv
- psutil (системный мониторинг)

## Источники данных и лимиты

- **Текущая погода:** Яндекс.Погода API с жестким лимитом 30 запросов в сутки (запрос раз в 1 час, интервал `3600000 ms`).
- **Прогноз на 5 дней:** Open-Meteo Daily Forecast API.
- **Кэширование:** все кэши (SVG-иконки, суточный счётчик запросов, последний ответ API) сохраняются в нетрекаемую директорию `.cache/`.
- **Иконки погоды:** векторные SVG Яндекс.Погоды в стиле `flat`, кэшируемые в `.cache/weather_icons/`.
- **Конфигурация:** `config.py` (считывает переменные окружения из `.env`, координаты `WEATHER_LAT` и `WEATHER_LON` обязательны для выполнения запросов).

## Архитектура проекта

- `main.py` — точка входа, конфигурация окна (1920x480 fixed size) и сборка основного макета.
- `config.py` — конфигурационные параметры (координаты, ключи API, интервалы).
- `fonts/` — локальные шрифты семейства Inter (статические и вариативные начертания).
- `commitlint.config.js` — конфигурация Conventional Commits.
- `api/` — клиенты интеграций:
  - `constants.py` — общие константы погодных условий, иконок и направлений ветра.
  - `weather_client.py` — асинхронное получение текущей погоды (Яндекс с защитой лимита) и 5-дневного прогноза (Open-Meteo).
- `widgets/` — независимые модули интерфейса:
  - `clock.py` — аналоговые часы с плавным ходом и таймером.
  - `calendar.py` — интерактивный календарь.
  - `weather_icons.py` — менеджер загрузки, кэширования и рендеринга векторных иконок погоды темы `flat` через `QSvgRenderer`.
  - `weather_widget.py` — виджет погоды с поддержкой компактного и полного режима отображения прогноза и иконок.
  - `pc_status_widget.py` — виджет мониторинга нагрузки процессора и оперативной памяти.

## Правила разработки и коммитов

- Никаких комментариев в коде без явной необходимости.
- Модульность: каждый компонент реализуется в отдельном файле.
- Фиксированное разрешение окна 1920x480 без возможности изменения пользователем.
- Трёхколоночная раскладка: слева — календарь (460px), по центру — погодный/системный виджет, справа — часы (460px).
- Форматирование коммитов по стандарту Conventional Commits с Git-хуком `commit-msg`.
- Стиль описания коммитов на русском языке — строго в прошедшем времени через краткие страдательные причастия без лишних склонений (по стилю `aechat-links`), например:
  - `настроен...`, `настроена...`, `настроены...`
  - `добавлен...`, `добавлена...`, `добавлены...`
  - `реализован...`, `реализована...`, `реализованы...`
  - `исправлен...`, `исправлена...`, `исправлены...`
  - `обновлён...`, `обновлена...`, `обновлены...`
- Не предлагать и не выполнять компиляцию пакетов и файлов (py_compile, pip-tools compile, pyinstaller и т.п.).
- Минималистичный и чистый интерфейс.
